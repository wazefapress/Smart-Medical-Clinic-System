## 🌍 النسخة العربية

نظام طبي ذكي وخفيف مبني للعمل عبر بيئات التطوير المحلية (مثل Termux) أو الخوادم السحابية. يهدف المشروع إلى رقمنة عملية استقبال المرضى، حيث يتيح لهم إدخال بياناتهم وأعراضهم عبر استمارة تفاعلية متعددة الخطوات، مع تقديم تحليل مبدئي للحالة باستخدام الذكاء الاصطناعي. كما يوفر لوحة تحكم آمنة للأطباء لإدارة السجلات بكفاءة.

### ✨ الميزات الرئيسية
* **واجهة مريض تفاعلية (Multi-step Form):** تجربة مستخدم سلسة لجمع البيانات مقسمة إلى خطوات.
* **تحليل مبدئي بالذكاء الاصطناعي:** تكامل مع OpenAI API لتقييم الأعراض بشكل فوري.
* **لوحة تحكم آمنة:** لوحة إدارة محمية بكلمة مرور (الافتراضية: `admin123`).
* **بحث فوري (Live Search):** فلترة السجلات الطبية بالوقت الفعلي بدون إعادة تحميل الصفحة.
* **إدارة متقدمة للبيانات:** إمكانية عرض التفاصيل المعمقة عبر نوافذ منبثقة (Modals)، وتصدير جداول المرضى إلى ملفات Excel (CSV).
* **تصميم متجاوب بالكامل:** واجهات تدعم جميع الشاشات مبنية باستخدام Tailwind CSS.

### 🛠️ التقنيات المستخدمة
إليك ملخص شامل للتقنيات والبرمجيات (Tech Stack) المستخدمة في بناء وتشغيل نظام العيادة الطبية الذكية:

---

### 1. الواجهة الأمامية (Frontend)

* **HTML5 / JavaScript (Vanilla JS):** لبناء هيكل الصفحات (استمارة المرضى ولوحة التحكم) وإدارة تفاعلات المستخدم وإرسال الطلبات للخادم.
* **Tailwind CSS:** إطار عمل لتصميم واجهات مستخدم عصرية، متجاوبة، وسريعة عبر تضمينه بواسطة CDN.
* **CSS3 (`style.css`):** لتخصيص الخطوط (مثل خط Cairo)، الألوان، وتحسين تجربة التمرير.

---

### 2. الخادم وخلفية النظام (Backend & Server)

* **Node.js:** بيئة تشغيل JavaScript على السيرفر.
* **Express.js:** إطار عمل خفيف وسريع لبناء مسارات الخادم (API Endpoints) ومعالجة طلبات `GET` و `POST`.
* **CORS:** وسيط أمني للسماح للمتصفح بالتواصل بين الواجهة الأمامية والخلفية.
* **Body-Parser:** لتحليل البيانات القادمة من نموذج الاستمارة بصيغة JSON.
* **Dotenv (`dotenv`):** لإدارة متغيرات البيئة وحماية المفاتيح السرية محلياً.

---

### 3. قاعدة البيانات (Database)

* **SQLite:** قاعدة بيانات خفيفة ومدمجة تُحفظ في ملف محلي (`clinic.db`) لتخزين بيانات استمارات المرضى وتاريخ التحليلات بسهولة دون الحاجة لخادم قواعد بيانات منفصل.

---

### 4. الذكاء الاصطناعي (AI Integration)

* **Google Gemini API (`@google/generative-ai`):** الحزمة البرمجية الرسمية والمستقرة للاتصال بنماذج جوجل الذكية.
* **نموذج `gemini-1.5-flash`:** النموذج المستخدم لتحليل أعراض المرضى وتقديم التقييمات الطبية المبدئية بسرعة ودقة باللغة العربية ومجاناً.

---

### 5. النسخ الاحتياطي وإدارة الأكواد (Version Control)

* **Git & GitHub:** لإدارة نسخ المشروع، تتبع التعديلات، وحفظ الأكواد في مستودع سحابي مع استبعاد الملفات الحساسة مثل `.env` و قاعدة البيانات.

---

### 6. الاستضافة والنشر (Cloud Hosting)

* **Render:** منصة السحاب المستضيفة لخادم Node.js على مدار الساعة عبر ربطها التلقائي بمستودع GitHub، مع تشغيل المتغيرات السرية أمنياً عبر لوحة تحكم المنصة.

للدخول إلى نظام العيادة الطبية الذكية وإدارته، يمكنك استخدام الواجهتين التاليتين بناءً على دورك (مريض أو مسؤل النظام):

---

### 1. واجهة استمارة المرضى (Public Portal)

* **رابط الاستخدام المحلي:** `http://localhost:3000`
* **رابط الاستخدام السحابي (بعد النشر على Render):** `[https://wazefapress.github.io/Smart-Medical-Clinic-System/](https://wazefapress.github.io/Smart-Medical-Clinic-System/)`
* **الاستخدام:** مخصصة للمرضى لتعبئة البيانات الشخصية، العمر، تحديد شدة الأعراض، ووصف الحالة للحصول على التحليل الفوري من ذكاء Gemini الاصطناعي.

---

### 2. لوحة تحكم المسؤول (Admin Dashboard)

* **طريقة الوصول:** من خلال فتح صفحة لوحة التحكم (`admin.html`) المرتبطة بخادمك.
* **الحماية:** اللوحة محمية بكلمة مرور لتأمين سجلات المرضى.
* **كلمة المرور الافتراضية:** `admin123`
* **الاستخدام:** تتيح لك استعراض كافة السجلات الطبية المخزنة في قاعدة البيانات، البحث في الحالات، تصدير البيانات إلى ملفات CSV، ومراجعة تحليلات الذكاء الاصطناعي السابقة.
